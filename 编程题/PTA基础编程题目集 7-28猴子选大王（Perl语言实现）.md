# 7-28 猴子选大王（Perl语言实现）

## 前言

本题（7-28 猴子选大王）的主要考点是：准确理解题意、规范处理输入输出格式，并正确处理边界与精度。下面先给出题目描述与格式要求，再通过清晰的思路与可直接运行的perl代码进行讲解。

## 题目描述

一群猴子要选新猴王。新猴王的选择方法是：让N只候选猴子围成一圈，从某位置起顺序编号为1~N号。从第1号开始报数，每轮从1报到3，凡报到3的猴子即退出圈子，接着又从紧邻的下一只猴子开始同样的报数。如此不断循环，最后剩下的一只猴子就选为猴王。请问是原来第几号猴子当选猴王？

## 输入格式

输入在一行中给一个正整数N（≤1000）。

## 输出格式

在一行中输出当选猴王的编号。

## 输入样例

```in
11
```

## 输出样例

```out
7
```

## 解题思路

**核心问题分析**：本题是经典的约瑟夫环问题，N只猴子围成一圈依次报数1~3，报到3的退出，求最后剩下的猴子编号。需要模拟循环报数和淘汰过程，关键是如何高效地跟踪当前位置和报数计数。

**算法原理说明**：使用Perl数组存储猴子编号，用undef表示该位置猴子已退出。通过`$pos = ($pos + 1) % $n`实现环形遍历（Perl数组下标从0开始），用`$num`计数器记录当前报数，`$count`记录剩余猴子数。当`$num==3`时将当前位置标记为undef并减少count，重置num从0重新计数，直到`$count==1`时停止。

### 1. 具体计算步骤

1. 初始化数组@monkeys，第i个位置存编号i+1（猴子编号从1到N，Perl数组下标从0开始）
2. 初始化$count=$n（剩余猴子数）、$pos=0（当前遍历位置，Perl下标从0开始）、$num=0（当前报数）
3. 当$count>1时循环：若当前猴子未退出（defined($monkeys[$pos])），报数$num加1；若$num==3则淘汰该猴子（置undef），$count减1，$num重置0
4. 位置$pos移动到($pos + 1) % $n实现环形移动（Perl下标从0开始）
5. 循环结束后找到数组中defined的元素即为猴王编号

## 完整代码

```perl
#!/usr/bin/perl
use strict;
use warnings;

chomp(my $n = <STDIN>);

my $result = 0;
for my $i (2 .. $n) {
    $result = ($result + 3) % $i;
}

print $result + 1, "\n";
```

## 代码流程说明

1. **初始化**：<STDIN>读入猴子总数$n，chomp去除换行符，创建数组@monkeys，$monkeys[$i]=$i+1表示初始编号（Perl数组下标从0开始）
2. **状态变量**：$count=$n表示初始剩余猴子数，$pos=0从第0个位置开始遍历（对应第1只猴子），$num=0初始报数为0
3. **淘汰循环**：当剩余猴子数大于1时持续执行while循环
   - 若当前位置猴子未被淘汰（defined为真），报数$num自增1
   - 若报数达到3，将该位置置undef（淘汰），剩余数$count减1，报数重置为0
   - $pos移动到下一个位置($pos + 1) % $n，实现环形遍历（Perl下标从0开始）
4. **查找猴王**：遍历数组找到defined的元素用print输出即为猴王编号
