# 7-30 字符串的冒泡排序（Perl语言实现）

## 前言

本题（7-30 字符串的冒泡排序）的主要考点是：准确理解题意、规范处理输入输出格式，并正确处理边界与精度。下面先给出题目描述与格式要求，再通过清晰的思路与可直接运行的perl代码进行讲解。

## 题目描述

我们已经知道了将N个整数按从小到大排序的冒泡排序法。本题要求将此方法用于字符串序列，并对任意给定的K（<N），输出扫描完第K遍后的中间结果序列。

## 输入格式

输入在第1行中给出N和K（1≤K<N≤100），此后N行，每行包含一个长度不超过10的、仅由小写英文字母组成的非空字符串。

## 输出格式

输出冒泡排序法扫描完第K遍后的中间结果序列，每行包含一个字符串。

## 输入样例

```in
6 2
best
cat
east
a
free
day
```

## 输出样例

```out
best
a
cat
day
east
free
```

## 解题思路

**核心问题分析**：将冒泡排序算法扩展到字符串序列，按字典序升序排列字符串，执行K趟排序后输出中间结果。关键点在于使用Perl的字符串比较运算符比较字符串字典序，使用临时变量交换字符串内容。

**算法原理说明**：使用Perl数组存储N个字符串（下标从0开始），外层循环控制K趟排序，内层循环逐对比较相邻字符串。`$strs[$j] gt $strs[$j+1]`表示前者的字典序大于后者时需要交换位置。Perl使用gt/lt/eq等运算符进行字符串比较。第i趟排序后，末尾i个字符串已有序。

### 1. 具体计算步骤

1. 用<STDIN>读入第一行，chomp后split分割得到N（字符串数）和K（排序趟数）
2. 逐行读入N个字符串存入数组@strs（Perl下标从0开始），用chomp去除末尾换行符
3. 外层i从1到K执行K趟冒泡排序
4. 第i趟内层j从0到n-i-1（Perl下标从0开始），用gt字符串比较运算符比较$strs[$j]和$strs[$j+1]，若前者字典序大则用临时变量交换
5. K趟排序后逐行用print输出数组中的所有字符串

## 完整代码

```perl
#!/usr/bin/perl
use strict;
use warnings;

chomp(my $line = <STDIN>);
my ($n, $k) = split /\s+/, $line;

my @strs;
for my $i (0 .. $n - 1) {
    chomp(my $s = <STDIN>);
    push @strs, $s;
}

for my $i (0 .. $k - 1) {
    for my $j (0 .. $n - 2 - $i) {
        if ($strs[$j] gt $strs[$j + 1]) {
            my $tmp = $strs[$j];
            $strs[$j] = $strs[$j + 1];
            $strs[$j + 1] = $tmp;
        }
    }
}

print join("\n", @strs), "\n";
```

## 代码流程说明

1. **输入数据**：<STDIN>读入第一行，chomp去除换行后split /\s+/得到n和k，然后逐行读入n个字符串存入数组@strs，每个字符串用chomp去除末尾换行符
2. **K趟冒泡排序**：外层for my $i (1..$k)共k趟；内层for (my $j = 0; $j < $n - $i; $j++)用Perl字符串比较运算符gt比较相邻两个字符串字典序
3. **字符串交换**：若$strs[$j] gt $strs[$j+1]表示前串大于后串需交换，使用临时变量$tmp完成交换
4. **输出结果**：遍历数组，每行用print输出一个字符串加换行，即K趟排序后的中间结果
